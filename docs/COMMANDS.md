# SCC commands

🇧🇷 [Versão em português](COMMANDS.pt-BR.md)

Every `/scc` command of SCC – Super Cool Calculator, generated from the mod's own help texts. In game, **`/scc help`** shows the same list (only the commands you may use; click one to put it in the chat line), **`/scc help <command>`** the details and **`/scc help settings`** all server settings with their current value.

_Valid for SCC 1.4.1 and later (Minecraft 1.21.1 and 26.1.2). Generated by `tools/make_commands_doc.py`._

## Permissions

**Everyone** – any player. **Network owner** – the player who placed the network's Calculator Controller (or an operator); only matters while `/scc security on`. **Operator** – permission level 2, like `/gamerule` (in single player: cheats on).

## Commands

<a id="scc-help"></a>
### /scc help

Without an argument it lists every command you may use; click one to put it in the chat line. With a command name it shows the syntax, a description, an example and who may use it. Operators also get /scc help settings: every server setting with its current value, default and meaning.

- **Syntax:** `/scc help [command|settings]`
- **Example:** `/scc help trust`
- **Who:** everyone

<a id="scc-guide"></a>
### /scc guide

Opens the in-game manual, just like the SCC Manual item. With a chapter (for example start, network, storage, autocraft, processing, sky, forge, quarry, cosmos, power) it opens there; a second word jumps to a heading inside that chapter. Links in the chat use this command to point at the right page.

- **Syntax:** `/scc guide [chapter] [heading]`
- **Example:** `/scc guide quarry`
- **Who:** everyone

<a id="scc-sky"></a>
### /scc sky

Tells you which sky conjunction is active right now, how long it still lasts and when the next one starts. During a conjunction the Sky Harvester gets double yield of the two sky objects involved (setting conjunctions).

- **Syntax:** `/scc sky`
- **Example:** `/scc sky`
- **Who:** everyone

<a id="scc-shower"></a>
### /scc sky shower

Shows whether a meteor shower is running right now or how long it is until the next one. Meteor showers come on new moon nights (settings meteorShowers, meteorShowerEvery, meteorShowerMeteors): shooting stars all night and a few real meteors per player.

- **Syntax:** `/scc sky shower`
- **Example:** `/scc sky shower`
- **Who:** everyone

<a id="scc-order"></a>
### /scc order

Needs a linked Wireless Terminal in your inventory or Curios slot, in range of its antenna, and the right "order" on that network. Plans like the order window: if ingredients are missing, the chat lists them; otherwise the order starts and the chat shows the estimated time. Tab completes item IDs, items in your network first. Amount 1 to 9999, default 1.

- **Syntax:** `/scc order <item> [amount]`
- **Example:** `/scc order minecraft:iron_ingot 64`
- **Who:** everyone

<a id="scc-trust"></a>
### /scc trust

Stand next to your network (within 12 blocks of an SCC block). Rights are take, put, order and build, separated by commas; without rights the player gets all of them. Only matters while the setting security is on. The Security Terminal does the same in a window.

- **Syntax:** `/scc trust <player> [rights]`
- **Example:** `/scc trust Steve take,order`
- **Who:** the owner of the network or an operator (only matters while /scc security is on)

<a id="scc-untrust"></a>
### /scc untrust

Stand next to your network. While security is on, the player can no longer use it.

- **Syntax:** `/scc untrust <player>`
- **Example:** `/scc untrust Steve`
- **Who:** the owner of the network or an operator (only matters while /scc security is on)

<a id="scc-rights"></a>
### /scc rights

Stand next to your network. Only the owner (or an operator) may see the list.

- **Syntax:** `/scc rights`
- **Example:** `/scc rights`
- **Who:** the owner of the network or an operator (only matters while /scc security is on)

<a id="scc-settings"></a>
### /scc &lt;setting&gt;

/scc <setting> shows the current value, /scc <setting> <value> changes it at once for everyone and saves it in config/scc-server.json. On/off settings take on or off, all others a number in their allowed range. /scc help settings lists every setting with its default and meaning.

- **Syntax:** `/scc <setting> [value|on|off]`
- **Example:** `/scc meteorChance 25`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-power"></a>
### /scc power

Without on/off it shows the current value. Off: networks, machines and the Calculator Controller work without FE. Default: on.

- **Syntax:** `/scc power [on|off]`
- **Example:** `/scc power off`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-list"></a>
### /scc list

Opens a window with every setting, its value and a short explanation, with a search line. On the server console the list goes to the chat instead.

- **Syntax:** `/scc list`
- **Example:** `/scc list`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-reloadconfig"></a>
### /scc reloadconfig

Use it after editing the file by hand. The new values are sent to every player at once.

- **Syntax:** `/scc reloadconfig`
- **Example:** `/scc reloadconfig`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-doctor"></a>
### /scc doctor

Stand next to your network. Opens a report of what is connected, which recipe types the machines can run and where one is missing - the first thing to look at when an item seems impossible to craft. The report is also written to logs/scc.log.

- **Syntax:** `/scc doctor`
- **Example:** `/scc doctor`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-selftest"></a>
### /scc selftest

Builds a small test network next to you, checks the basic functions and removes it again. Only failures and the total appear in the chat; the full run is in logs/scc.log - handy for bug reports. Use it where there is some free space.

- **Syntax:** `/scc selftest`
- **Example:** `/scc selftest`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-unstick"></a>
### /scc unstick

If orders keep reporting no matching machine although one is there, a step filter may be stuck. This command clears all of them; whatever is still inside the machines goes back to storage. Running jobs at most repeat one started step.

- **Syntax:** `/scc unstick`
- **Example:** `/scc unstick`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-drain"></a>
### /scc drain

Repairs SCC blocks that an old bug left flooded: every waterlogged SCC block in the loaded chunks around you is drained (radius in chunks, default 8, 1-32). Cables you placed under water on purpose are drained as well.

- **Syntax:** `/scc drain [chunks]`
- **Example:** `/scc drain 4`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-profile"></a>
### /scc profile

/scc profile on starts measuring; play normally for a few minutes, then /scc profile shows the results in a window (and in logs/scc.log). /scc profile off stops it, /scc profile reset clears the measurements. Off by default and free while off.

- **Syntax:** `/scc profile [on|off|reset]`
- **Example:** `/scc profile on`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-balance"></a>
### /scc balance

Lists the values pack makers can change with data packs (data/scc/scc_balance/...). Use it to check whether your data pack took effect.

- **Syntax:** `/scc balance`
- **Example:** `/scc balance`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-meteor"></a>
### /scc meteor

Without a position it falls 24 to 48 blocks around you; with x y z it falls there. A Sky Harvester nearby catches it, otherwise it leaves a crater with a Meteorite - or burns up where blocks are protected. From the server console a position is required.

- **Syntax:** `/scc meteor [x y z]`
- **Example:** `/scc meteor ~ ~ ~20`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-conjunction"></a>
### /scc sky conjunction

Sets the time in every world to the closest moment of the next conjunction, like /time set. Meant for testing and for showing the effect.

- **Syntax:** `/scc sky conjunction`
- **Example:** `/scc sky conjunction`
- **Who:** operators only (permission level 2, like /gamerule)

<a id="scc-showerjump"></a>
### /scc sky shower jump

Sets the time in every world to just before sunset of the next meteor shower night, like /time set. Meant for testing and for showing the shower.

- **Syntax:** `/scc sky shower jump`
- **Example:** `/scc sky shower jump`
- **Who:** operators only (permission level 2, like /gamerule)
